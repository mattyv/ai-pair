# AI Pair Local Audio

This optional companion runs the Pair panel and speech on the local VS Code
client. Install it locally alongside AI Pair, then reload the window. In SSH,
WSL, and container windows, install the companion on the local client, not in
the remote workspace.

The ElevenLabs key belongs to the companion's local secret storage. Enter it
again in the local panel when moving from an earlier AI Pair installation.
Kokoro synthesis remains available only on supported Linux x64 systems.

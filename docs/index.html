AI Pair Programmer

This fork builds on the original AI Pair project.

Pair with a coding agent in VS Code, with controls for conversation order, reading pace, and code display.

  • Choose Typing, Lines, or Blocks for code playback.
  • Use optional local Kokoro narration after downloading its model, or choose ElevenLabs and add an API key securely in VS Code.
  • Preview voices and copy diagnostics for speech and session status without including keys or narration.

Explore the interactive architecture.

Download a fork build from GitHub Actions by opening a successful Build VSIX run and downloading its artifact.
